## Fluxo Kanban

A fazer → Em andamento → Em revisão/teste → Concluído.

## Critérios gerais de conclusão

Uma tarefa só será considerada concluída quando estiver implementada ou produzida, revisada/testada no escopo previsto e documentada quando necessário. Decisões institucionais ainda não confirmadas devem permanecer registradas como pendências, sem serem tratadas como requisitos definitivos.

## Organização do Git

- `main`: versão estável.
- `dev`: integração do desenvolvimento.
- Branches curtas `feature/nome-da-funcionalidade` para funcionalidades futuras.
