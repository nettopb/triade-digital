# Tríade Digital
## Projeto 10 — Plataforma Unificada de Acompanhamento Escolar

Aplicação web acadêmica para apoiar o acompanhamento da rotina escolar, reunindo informações de estudantes, turmas, frequência, comunicados e indicadores em um único ambiente.

## Objetivo
Desenvolver uma plataforma web que facilite o registro e a consulta de informações escolares, apoie a identificação de situações que exigem acompanhamento e ofereça informações organizadas para os diferentes perfis da comunidade escolar.

## Tecnologias
- PHP 8.2 ou superior
- MySQL
- PDO para acesso ao banco de dados
- Arquitetura MVC
- HTML5, CSS3 e JavaScript
- Bootstrap
- Git e GitHub

## Escopo inicial (MVP)
- Autenticação e controle de acesso por perfil
- Cadastro e gerenciamento de estudantes
- Cadastro e gerenciamento de turmas
- Registro de frequência
- Identificação de alertas de faltas consecutivas
- Comunicados escolares
- Painel e relatórios básicos

Funcionalidades como chat em tempo real, notificações push e integrações externas ficam fora do MVP e poderão ser avaliadas como evoluções futuras.

## Perfis previstos
- Professor
- Coordenação
- Direção
- Secretaria
- Gestão da Secretaria de Educação

Os níveis de acesso e as permissões serão detalhados nos requisitos e implementados gradualmente.

## Ambiente de desenvolvimento
O ambiente local inicial será XAMPP com PHP e MySQL. Dados utilizados durante o desenvolvimento acadêmico deverão ser fictícios. O uso de dados reais de estudantes dependerá da implementação e validação dos controles de segurança, privacidade, autorização e auditoria aplicáveis.
